# Retail Loan Default Risk Modelling Using Logistic Regression

## Overview

This project explores how statistical modelling can be used to assess retail loan default risk using a simulated consumer lending dataset.

## What I did

* Cleaned and explored the loan data
* Performed exploratory data analysis
* Built a logistic regression model
* Generated predicted probabilities of default
* Evaluated the model using a confusion matrix, sensitivity, specificity, precision, ROC-AUC and Gini
* Used predicted probabilities to segment borrowers by risk level

## Tools

* SAS
* Logistic Regression
* Statistical Modelling
* Credit Risk Analysis

## Key Result

The final model achieved a test AUC of approximately 0.87, indicating that the model was able to reasonably separate borrowers who defaulted from those who did not in the simulated dataset.

## Dataset

The dataset used in this project was obtained from Kaggle and was published by Lao Tse. It contains simulated consumer lending data covering borrower characteristics, loan characteristics and loan default outcomes.

Source: Kaggle - Lao Tse
